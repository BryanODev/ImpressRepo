# Impress Classic Navbar — Single Link block

## Install
Replace ONLY `sections/impress-classic-navbar.liquid` in your current theme.

## Configure
1. Shopify Admin → Online Store → Themes → Customize → Header → Impress Classic Navbar.
2. Click **Add block** → **Single Link**.
3. Enter a **Link label** (for example: Inicio, Contacto, Nosotros, Ofertas).
4. Choose a **Link destination**. This is required for the link to appear on the storefront.
5. Drag the block to the order you prefer. Keep **Dropdown Product Card** blocks directly after their **Navigation Group**.

The new link displays as an ordinary clickable link without an arrow or dropdown. On mobile it appears in the vertical menu and navigates directly on tap. Existing Navigation Groups still open their usual product submenus with icons and a Back button.

All existing navigation blocks, original Impress Header, account menu, cart, sticky behavior, font-size controls, and desktop/mobile layouts are preserved. No Shopify metafield changes needed.
