# Impress — process steps layout polish

This is a replacement-files package (not a complete Shopify theme).

## Install

1. In **Online Store → Themes → Edit code**, replace `sections/impress-order-instructions.liquid`.
2. You **do not** need to upload the PNG icons again if you installed the previous icon package. They are included here unchanged only for convenience.
3. Preview the home page on desktop and mobile.

## Changes

- Number badge beside each title: **28px** instead of 36px.
- Description begins at the **left edge of the card**, below the numbered heading; it no longer inherits a 48px indentation.
- Step icon is **horizontally centered** above its title.
- Icons display **40% larger by default**, including on sections that previously saved an 80px icon size (80px × 140% = 112px). This preserves the previously saved **Icon size** setting.
- New Theme Editor setting **Icon enlargement** (100–160%, default 140%) provides independent control without disrupting your existing text or uploaded icons.

No Shopify products, variant mappings, cart, artwork editor, upload flow, or other theme sections are modified.
