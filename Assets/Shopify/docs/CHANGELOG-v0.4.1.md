# Changes in v0.4.1

- Shared paper-product UI now matches Sticker/Banner controls and styling.
- Added icon tiles: orientation and one/two-sided printing.
- Flyer quarter-page portrait default; variant alias for existing landscape-formatted size label.
- Banner can rotate its preview orientation; grommets and rear board guide positions follow displayed orientation.
- The shared editor core supplies click-to-upload behavior to sticker, banner, and both paper editors.
- Original upload fields remain in their current locations.

Note: the change is interface/configuration only; no variant prices, production bleed generation or backend workflows were added.
