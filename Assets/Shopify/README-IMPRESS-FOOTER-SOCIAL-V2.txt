IMPRESS | FOOTER — SOCIAL ICONS V2
================================
Copy these files into your DEVELOPMENT theme, keeping their folders:

sections/impress-footer.liquid            REPLACE
assets/impress-footer-facebook.svg        REPLACE (white square icon)
assets/impress-footer-instagram.svg       ADD if missing (from last update)
assets/impress-footer-whatsapp.svg        ADD if missing (green contact-button icon)
assets/impress-footer-whatsapp-white.svg  ADD (new separate white social icon)
assets/impress-footer-credit-logo.png     ADD if missing (your Impress credit logo)

The footer now displays Instagram, Facebook and white WhatsApp as isolated
white SVG logos, NOT rounded buttons. The existing WhatsApp contact button
stays exactly as before, with its original green icon. 'Hecho por' / Impress
logo credit, menus, contact and Shopify links are preserved.

Customize > Impress Footer > Iconos de redes sociales:
- Enable/disable each of Instagram, Facebook and white WhatsApp.
- Edit the existing Instagram and Facebook links.
- Optional separate WhatsApp social link. If blank, it uses the same number
  already entered in the footer's main WhatsApp contact setting.
- Optionally upload replacement images for each social icon. Uploaded icons
  are automatically rendered white (preserve transparency for best results).
- Adjust all three icon sizes, spacing, opacity and left/center/right alignment.

Note: Instagram/Facebook only display when their links are configured.
If you want to see a brand immediately, enter its link in Theme Editor.
The default icons and white coloring are provided automatically.

Only the 1 footer section and its assets change. No theme layout or other
section is modified.
