STEP 1: Install shared Impress Stand section before templates.

Copy these files into the SAME Shopify development theme:
 sections/impress-stand-configurator.liquid
 assets/impress-stand-configurator.css

Wait until the upload confirms that sections/impress-stand-configurator.liquid exists in the remote theme. In Shopify Admin > Online Store > Themes > (the same development theme) > Edit code, verify that file appears in Sections.

Then install STEP 2. Do NOT install templates first.
